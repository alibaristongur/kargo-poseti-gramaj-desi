# Kargo poşeti gramaj + desi referansı

S&M Ambalaj fabrika tartısı ve desi formülü. **Fiyat yok.**

## Desi formülü

```text
desi = (en_cm × boy_cm × kalinlik_cm) / 3000
```

- Birim: cm
- `/5000` ve mm kullanılmaz
- Boş poşet desisi: `0`
- Kapak payı (+4 / +5) açık boya eklenmez
